# PageWeave

Developed by [OmniCan.ca](https://omnican.ca).

Turn webpages into editable Figma layers, watch them rebuild, and record sharp WebM videos.

- [Landing page](https://spatsariya.github.io/pageweave-public/)
- [Latest release and downloads](https://github.com/spatsariya/pageweave-public/releases/latest)
- [Privacy policy](https://spatsariya.github.io/pageweave-public/privacy.html)

This public repository holds the landing page and release downloads. The development repository is private.

## Install

Download the latest `PageWeave-1.4.0.zip` release and extract it. In Chrome, open `chrome://extensions`, enable Developer mode, choose **Load unpacked** and select the extracted `extension` folder.

For Figma desktop, use **Plugins → Development → Import plugin from manifest** and choose `figma-plugin/manifest.json`. Run PageWeave Importer to import a `.pageweave.json` capture.

Requires Chrome 116+. The extension is distributed as an unpacked download; no Chrome Web Store listing is claimed here.
